# Internet frame assets

Combat now uses these downloaded transparent frame assets instead of procedural combat gradients:

- `fire/fire1_64.png`: Animated Fire, BenHickling, CC0 — https://opengameart.org/content/animated-fire
- `weapon-slash/unpacked/Classic/`: Weapon Slash - Effect, Cethiel, CC0 — https://opengameart.org/content/weapon-slash-effect

The existing transparent CC0 impact and lightning sheets remain available under `assets/vfx/cc0/combat/` and are used for their matching technique families.
