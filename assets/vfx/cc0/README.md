# Battle VFX sources

These transparent sprite sheets are used by the combat VFX layer:

- `explosion1.png`: CC0, Ben Hickling, OpenGameArt — https://opengameart.org/content/explosion-7
- `fire-circles/fire_circles_400x400.png`: CC0, Matriax, OpenGameArt — https://opengameart.org/content/fire-circle-fx
- `combat/slash.png`: CC0, tbbk, OpenGameArt — https://opengameart.org/content/pixel-art-sword-slash-effect
- `combat/lightning.png`: CC0, 13rice, OpenGameArt — https://opengameart.org/content/radial-lightning-effect
- `combat/hit-yellow.png`: CC0, Sinestesia, OpenGameArt — https://opengameart.org/content/hit-animation-frame-by-frame

The original sprite sheets are kept intact. The game crops their frames at runtime so the effects can be recolored or layered without introducing opaque backgrounds.
