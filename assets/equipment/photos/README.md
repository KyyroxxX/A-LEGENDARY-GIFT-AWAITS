# Fotos de objetos

Coloca aquí las imágenes de los objetos equipables para sustituir sus iconos SVG.

- Usa un archivo PNG, WebP o JPG por objeto.
- Nombra el archivo con el ID del objeto, por ejemplo `dedo_maldito.png`.
- Después añade `photo: 'assets/equipment/photos/dedo_maldito.png'` en el objeto correspondiente de `js/game/equipment.js`.
- Se recomienda una imagen cuadrada, con fondo transparente si el objeto lo permite.

Si una foto falla al cargar en la vista de equipamiento, conserva automáticamente el icono SVG de respaldo.
